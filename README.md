# Daisy Fong — Personal Portfolio

A single-page personal website built with **Next.js 15**, React, and Tailwind CSS. Korean-inspired creamy minimalist design with smooth scrolling, photo wall, experience timeline, project cards, and modals.

## Features

- Fixed navigation with smooth scroll to sections
- Photo wall with click-to-enlarge modals
- Personality trait badges and clickable experience timeline
- Responsive project grid (1 → 2 → 3 columns)
- Contact section with email, LinkedIn, phone, and social icons
- Font Awesome 6 icons via CDN

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize content

Edit `src/data/content.ts` for your bio, photos, experiences, projects, and contact links.

## Build for production

```bash
npm run build
npm start
```
